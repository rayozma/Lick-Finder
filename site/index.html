Matching uses note intervals, so a melody matches in any key. Rhythm matching compares the time between note starts, so tempo does not matter, and close rhythms (for example swung eighths) still count. "Earliest" means earliest in this dataset, not the first use ever.

Chord search compares the steps between chord roots, so a progression matches in any key. Power chords and sus chords match both major and minor. The year is the release date on Spotify, which is sometimes a later reissue.
